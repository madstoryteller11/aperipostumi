# AperiPost(umi) — GitHub Pages v0.3.1 beta

Release beta pronta per essere pubblicata come PWA su iPhone, iPad, Android e
computer.

## Incluso

- applicazione nella cartella `www`;
- workflow GitHub Pages;
- installazione guidata per iPhone e Android;
- funzionamento offline;
- feedback beta esportabili in JSON/CSV;
- 8 mazzi e 320 carte.

- `PUBBLICAZIONE_GITHUB_PAGES.md`
- `INSTALLAZIONE_IPHONE_ANDROID.md`
