# Installazione sui telefoni

Link previsto:

`https://polu11.github.io/aperipostumi/`

## iPhone e iPad

1. Apri il link con Safari.
2. Tocca Condividi.
3. Tocca Aggiungi alla schermata Home.
4. Attiva Apri come app web.
5. Tocca Aggiungi.

## Android

1. Apri il link con Chrome o un browser compatibile.
2. Premi Installa dentro AperiPost(umi).
3. Conferma.

Quando il comando automatico non compare, usa il menu del browser e scegli
Installa app oppure Aggiungi a schermata Home.

## Dati locali

Prima di rimuovere l'app o cancellarne i dati:

- Dati → Esporta feedback JSON
- Dati → Esporta backup
